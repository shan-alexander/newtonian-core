# Gateway

Authority. The machine emits intent. The gateway admits, refuses, or drops. I/O happens *beside* the trait, in the Executive or a sibling process.

Actuate out of band. Reconcile in band. Never give the machine a client to call.

Hardware estop, venue cancel-on-disconnect, Kubernetes admission, UI sandbox, TLS policy — all gateways. Domain-specific. Not this crate’s types.

`OpenGateway` is a named hole for tests.
