# Mandate

Standing desires. Not a state. Not a belief. Not a `Cmd`.

Limits, calendars, “must be done by,” the universe of names the program may talk about. Changes rarely. When it changes, the Executive injects a `Msg`.

YAML knobs deserialize into mandate (and lift bounds). They do not deserialize into XOR children. See [[docs/adr/0012-yaml-is-knobs-not-topology]].

A mandate survives Halted → Armed. See [[docs/edge_cases/mandate-survives-halt]].
